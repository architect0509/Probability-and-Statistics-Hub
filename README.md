# Probability-and-Statistics-Hub
수원대학교 컴퓨터공학부 1학년 수학2 [파이썬으로 배우는 확률과 통계]의 내용을 다루고 있습니다. 개념과 공식을 쉽게 이해하고 주요 문제를 정복할 수 있도록 돕습니다.

- **1학기**: 4장 확률변수와 확률분포 · 5장 여러가지 확률분포 · 6장 표본분포
- **2학기**: 7장 통계적 추정 · 8장 검정 · 9장 범주형 자료분석 (9장은 아직 수업 예제만)

화면 위쪽의 **1학기 / 2학기** 버튼으로 학기를 바꾸면 문제풀이 · 개념 사전 · 공식 사전 · 모의 테스트 · 흐름잡기가 해당 학기 내용으로 바뀝니다.

## ⚔️ 벨레스타 연대기 (game/)

헤더의 **모험 입장** 버튼으로 들어가는 탑다운 중세 RPG입니다. 2학기(7~9장) 내용을 NPC 대화, 표지판, 퀴즈로 배웁니다.

- 조작: 방향키/WASD 이동, E·Space 상호작용, 마우스 휠·핀치·± 버튼 줌, Enter로 컷씬 넘기기
- 문제를 모르면 「📐 공식 힌트」(무료)나 「📖 자세한 풀이」(보상 절반)를 누르거나 입력창에 「모르겠다」라고 쓰면 됩니다. 틀리면 풀이가 자동으로 나옵니다.
- 상자·통은 밀 수 있고, 꽃·버섯·뼈는 주울 수 있고, 덤불·나무·통은 뒤질 수 있습니다. 바뀐 맵은 저장됩니다.
- 캐릭터 그림 교체: `game/assets/portraits/<id>.png` (표정별 `<id>_<mood>.png`), 도트는 `game/assets/sprites/<id>.png` (3열×4행). 아이디 목록은 `game/assets/캐릭터_목록.md`.
- 메인 스토리 10장: 특정 장소에 가면 컷씬이 나오고 진행도가 오릅니다 (퀘스트 창에서 확인).
- 대사 속 파란 밑줄 용어에 마우스를 올리면(모바일은 탭) 개념과 예시가 나옵니다.
- 장소마다 배경음악이 다르고, 밤에는 밤 버전으로 바뀝니다.
- 저장은 브라우저(localStorage)에 됩니다.
- 이동: 모바일은 화면 왼쪽 아래 아무 데나 눌러 생기는 **조이스틱**(8방향, 살짝 밀면 천천히), PC는 방향키 두 개를 같이 누르면 대각선.
- **동서남북**: 북문 → 왕성(국왕·근위대장·서기·왕녀), 서문 → 「추정의 지하수로」(표지판 5개), 남문 → 「검정의 폐성채」(12개), 동문 → 숲 끝 「범주의 화염 미궁」(20개). 던전 수호자는 문제를 맞혀야 길을 비킨다.
- **모험가 길드 「표본의 잔」**: 랭크(F~S), 하루 5건 의뢰, 길드마스터 시험.
- **📍 길 안내**: 퀘스트 창에서 안내할 퀘스트를 고르면 노란 발자국과 화면 가장자리 화살표로 경로를 보여 준다.
- **📜 오늘의 칙령**: 광장 큰 벽보의 공식이 날짜(한국 시간)마다 바뀐다. 칙령 시험은 하루 한 번 포상.
- **시네마틱 컷씬**: 레터박스 · 줌인/줌아웃 · 인물이 걸어 들어오는 연출. 대사 형식은 `js/cinema.js` 맨 위 주석 참고.
- **돌발 이벤트 · 돌발 퀴즈 · 편향단**: 걷다 보면 「투다다다닷!」, 출제자, 끈질긴 3인조 편향단이 나타난다. 설정에서 빈도 조절.
- **이지 쌤**: 표지판을 3·6·10·15…개 모을 때마다 뛰어와서 개념을 아주 쉽게 설명해 준다.
- 수식 속 기호는 밑줄을 누르면 뜻이 나오고, 공식 상자 아래에 「🔣 기호 풀이」가 붙는다.
- 모든 인물 그림은 `game/assets/portraits/` 의 일러스트를 쓴다. 새 인물은 `pic` 으로 기존 일러스트를 빌린다.
- 카카오톡 공유 미리보기: `og-image.jpg`, `game/og-image.jpg` (주소는 `https://architect0509.github.io/Probability-and-Statistics-Hub/` 기준).
